# Allegro Subiekt 123

## Application information

**Version:** 1.0.0

Private integration between Allegro and Subiekt 123.

The application is used exclusively for the owner's Allegro account. It reads order information from Allegro REST API and uses the order data to automatically create sales documents in Subiekt 123.

## Permissions

The application uses only:

`allegro:api:orders:read`

The application does not create, modify or delete Allegro offers and does not manage other sellers' accounts.

## Purpose

Automatic creation of sales documents in Subiekt 123 based on orders placed on the owner's Allegro account.
